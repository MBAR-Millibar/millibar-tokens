# Code of Conduct

This project follows the [Millibar.io Code of Conduct](https://github.com/MBAR-Millibar/Code-of-Conduct/blob/main/CODE_OF_CONDUCT.md), which covers our online community, including this repository's issues and pull requests.

To report behaviour that breaks the code, email [conduct@millibar.io](mailto:conduct@millibar.io). Never describe an incident or name people in an issue or pull request. Reports are handled confidentially.
