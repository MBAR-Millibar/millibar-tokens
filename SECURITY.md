# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's vulnerability reporting](https://github.com/MBAR-Millibar/millibar-tokens/security/advisories/new), or email [hello@millibar.io](mailto:hello@millibar.io) with "Security" in the subject.

Include what you found, how to reproduce it, and which version (tag) is affected. We'll confirm we received it, keep you updated, and credit you in the release notes unless you'd rather not be named.

## Supported versions

Only the latest release gets fixes. Projects pin a tag, so upgrade to the newest [release](https://github.com/MBAR-Millibar/millibar-tokens/releases/latest) to get them.

## Scope

The package is static CSS, a Tailwind preset, JSON and SVG files, with no runtime code. The SVG logos are inlined by projects, so markup or scripts in them count. For Millibar's apps and infrastructure, see [millibar.io/security](https://millibar.io/security).
